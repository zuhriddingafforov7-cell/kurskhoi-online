# Biyomuz Academy UI Generator (Плагини Лабораторияи №9)

Ин плагини **Figma Desktop** мувофиқи талаботи расмии **Лабораторияи №9 («Дизайн в Figma»)** ва сохтори воқеии вебсайти **Biyomuz Academy** таҳия шудааст.

## Файлҳои плагин
- [`manifest.json`](file:///C:/Users/ZUHRIDDIN/Desktop/kurskhoi-online/tools/figma-biyomuz-plugin/manifest.json) — конфигуратсия (`api: 1.0.0`, `documentAccess: "dynamic-page"`)
- [`ui.html`](file:///C:/Users/ZUHRIDDIN/Desktop/kurskhoi-online/tools/figma-biyomuz-plugin/ui.html) — интерфейси интихоби забон (`Тоҷикӣ` — асосӣ / `Русский` — иловагӣ) ва тугмаи **`Сохтани дизайни Biyomuz Academy`**
- [`code.js`](file:///C:/Users/ZUHRIDDIN/Desktop/kurskhoi-online/tools/figma-biyomuz-plugin/code.js) — сохтори 4 саҳифа (`01 Flow`, `02 Wireframes` бо 8 экран, `03 UI-kit`, `04 Mockups` бо 8 Desktop + 1 Mobile + Footer + 2 Overlay), 14 `PaintStyle`, 5 `TextStyle` (танҳо `Noto Sans`), `Button` (Variants + Text Property `Label`), `Input` (4 ҳолат), `CourseCard` (Auto Layout + `Курсро дидан`), шабакаҳои расмии `12×88+24` ва `4×16+16`, `exportSettings` PNG 1x ва прототипи кликшаванда (`NAVIGATE`, `BACK`, `OVERLAY`, 1 Flow Starting Point дар `/`).
