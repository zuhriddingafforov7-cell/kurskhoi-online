## 2. Андозаҳои санҷидашудаи экран (Viewports)

Ҳамаи саҳифаҳо дар муҳаррики воқеии Chromium/Chrome дар ду андозаи калидии зерин озмуда шуданд:

1. **Мобилӣ (Mobile):** `390 × 844 px`
   - Набудани ҳаракати уфуқӣ (horizontal overflow $x = 0$).
   - Менюи мобилии «гамбургер» (`.navbar-toggler`) бо кушодашавӣ ва пӯшидашавии мураттаб.
   - Кортҳои курсҳо ва ҷадвалҳои семантикӣ ба намуди кортҳои блокии амудӣ (`flex-direction: column`).
   - Ҳамаи тугмаҳо ва майдонҳои интихобӣ дорои андозаи бехатари $\ge 44 \times 44\text{ px}$.

2. **Компютер (Desktop):** `1280 × 800 px`
   - Сеткаи 12-сутунаи Bootstrap 5.3 бо тақсимоти сутунҳои асосӣ ва паҳлӯӣ (`.col-lg-8` ва `.col-lg-4` / `.col-lg-3` ва `.col-lg-9`).
   - Намоиши мураттаби шрифтҳои миллии Noto Sans бо фарогирии пурраи алифбои кириллии тоҷикӣ.
   - 0 хатогӣ дар консоли таҳиягарон (Chrome DevTools).

## 5. Хатогиҳои ёфтшуда ва ислоҳшуда

1. **Нишони худсаронаи «PRO» дар Navbar:**
   - *Хато:* Дар сарлавҳаи саҳифа дар паҳлӯи номи лоиҳа нишони `<span class="navbar-brand-badge">PRO</span>` вуҷуд дошт, ки дар макети аслии Figma набуд.
   - *Ислоҳ:* Нишони «PRO» пурра ҳазф карда шуда, намуди зоҳирӣ 100% ба макети аслӣ мутобиқ гардид.

2. **Рамзгузории аломатҳои SVG дар Data URI:**
   - *Хато:* W3C Validator мавҷудияти фосилаҳоро дар сатри `src="data:image/svg+xml,..."` ҳамчун хатои синтаксисӣ қайд кард.
   - *Ислоҳ:* Тасвирҳои векторӣ ба формати стандартии `data:image/svg+xml;base64,...` гузаронида шуданд, ки масъаларо пурра бартараф сохт.

3. **Мутобиқати сатҳи сарлавҳаҳо (Heading Outline):**
   - *Хато:* Дар бахши Footer тегҳои `<h5>` пас аз `<h2>` ё `<h3>` омада, сатҳҳоро мепарониданд (Skipped heading levels).
   - *Ислоҳ:* Ба тегҳои мантиқии `<h3 class="h5">` иваз карда шуданд, ки ҳам намуди визуалии CSS-ро бетағйир нигоҳ дошт ва ҳам дарахти сохтории сарлавҳаҳоро мукаммал сохт.
