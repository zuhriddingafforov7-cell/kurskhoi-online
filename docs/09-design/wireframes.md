# User Flow ва Вайрфреймҳои Biyomuz Academy (`docs/09-design/wireframes.md`)

Мутобиқи талаботи Лабораторияи №9, пеш аз сохтани макетҳои ниҳоӣ **2 User Flow** (дар саҳифаи `01 Flow`) ва **8 вайрфрейми Desktop** (дар саҳифаи `02 Wireframes`) дар андозаи `1440 × 1024 px` бо блокҳои хокистарии бе ранги бренд ва матнҳои воқеии тоҷикии Biyomuz Academy таҳия шудаанд.

---

## 1. Ду сенарияи User Flow дар саҳифаи `01 Flow`

Сенарияҳо бевосита аз User Stories (`docs/03-short-spec.md`) ва маршрутҳои воқеии `routes/web.php` гирифта шудаанд:

1. **Сенарияи 1 (Донишҷӯ · `US-01 / US-02 / US-03` — Боздид, номнависӣ ба курс, омӯзиши дарсҳо ва супоридани вазифа):**
   `/` → `/courses` → `/courses/{course}` → `/login · /register` → `[POST /student/courses/{id}/enroll]` → `/student/lessons/{lesson}` → `/student/assignments/{id}` → `[POST /student/assignments/{id}/submit]` → `/student/dashboard (Overlay)`
2. **Сенарияи 2 (Муаллиф ва Маъмур · `US-06 / US-04 / US-05` — Эҷоди курс, модулҳо, санҷиши вазифа ва тасдиқ):**
   `/login` → `/author/dashboard` → `/author/courses/create` → `/author/courses/{id}/modules` → `[PATCH /author/courses/{id}/submit]` → `/admin/courses · /author/submissions` → `[PATCH /admin/courses/{id}/approve|reject]` → `/courses (Нашршуда)`

---

## 2. Шабака ва қоидаҳои вайрфрейм дар саҳифаи `02 Wireframes`

- **Андозаи фрейм:** `1440 × 1024 px`.
- **Layout Grid:** `Columns`, **12 сутун**, **Type `Center`**, **Width `88 px`**, **Gutter `24 px`** (паҳноии муҳтавои марказӣ: `1320 px` = `.container` дар Bootstrap 5.3).
- **Рангҳо:** танҳо ранги хокистарӣ (`#475569`, `#CBD5E1`, `#E2E8F0`, `#F1F5F9`, `#FFFFFF`) — бе рангҳои ниҳоӣ.
- **Матнҳои намунавӣ:** воқеӣ ба забони тоҷикӣ мувофиқи сомона ва пойгоҳи додаҳои Biyomuz Academy (`Фарҳод Раҳимов`, `Устод Аҳмад Раҳимов`, `Ғаффоров Зуҳриддин`, `Кор бо Laravel`, `Асосҳои барномасозӣ`), бидуни `Lorem ipsum`.

| № | Номи фрейм (Маршрути Laravel) | Сохтор аз рӯи шабакаи 12-сутуна |
|---|---|---|
| 1 | `/ (Саҳифаи асосӣ)` | Сарсаҳифа (`1440×72 px`) + баннери Hero (*«Имрӯз биёмӯз, фардо муваффақ шав!»*) бо ду тугма (`Каталоги курсҳо →`, `Бақайдгирӣ`) + 4 корти омор (`8`, `4`, `16`, `3`) + нишонҳои категорияҳо + `Курсҳои машҳур` + Footer |

| 3 | `/courses` | Сарсаҳифа + сарлавҳа бо тугмаи `+ Курси нав` + **`.col-3` (`312 px`)**: филтрҳо (`Категория`, `Сатҳ`, `Ҷустуҷӯ`) + **`.col-9` (`984 px`)**: сатри ҷустуҷӯ, 3 корти курс (бо тугмаи `Курсро дидан`), пагинатсия + Footer |
