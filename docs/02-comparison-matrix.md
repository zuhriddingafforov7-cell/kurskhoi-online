# Матритсаи муқоисавии аналогҳо: Платформаи курсҳои онлайни «Biyomuz»

**Ҳадафи муқоиса:** Муайян кардани бартариятҳо ва камбудиҳои системаҳои мавҷудаи таҳсилоти онлайн, асосноккунии зарурати таҳияи платформаи мустақили «Biyomuz» ва интихоби беҳтарин қарорҳои меъморӣ ва функсионалӣ барои маркази таълимӣ.
**Санаи санҷиши маълумот:** 09.11.2026.

## 1. Меъёрҳои муқоиса ва шкалаи баҳогузорӣ

Меъёрҳои муқоиса пеш аз омӯзиши аналогҳо муқаррар шудаанд ва бевосита аз таҳлили соҳаи предметӣ ва равандҳои кории Лабораторияи №1 бармеоянд. Маҷмӯи меъёрҳо 10 ададро ташкил медиҳад (5 меъёри функсионалӣ ва 5 меъёри ғайрифунксионалӣ).

### 1.2. Шарҳи муфассали шкалаи баҳогузорӣ

Барои таъмини объективияти баҳогузорӣ барои ҳар як меъёр шкалаи ягонаи сезинагӣ (0, 1, 2) истифода мешавад:
- **0** — Имконият вуҷуд надорад ё қобили қабул нест;
- **1** — Қисман мавҷуд аст ё маҳдудиятҳои ҷиддӣ дорад;
- **2** — Мавҷуд аст ва ба талаботи муқарраршуда пурра ҷавоб медиҳад.

Тавсифи дақиқи ҳар баҳо аз рӯи меъёрҳо:
* **K1 (Эҷод ва модератсияи курсҳо):**
  * `0` — Воситаи дохилии эҷоди курс вуҷуд надорад.
  * `1` — Эҷоди курс мавҷуд аст, аммо модератсияи ҳатмии пеш аз нашр вуҷуд надорад ё нақши муаллифи оддӣ аз эҷоди мустақилонаи курси нав маҳдуд аст.
  * `2` — Муаллиф курсро месозад ва пеш аз нашр раванди ҳатмии тасдиқ ва модератсия аз ҷониби маъмур/платформа амалӣ мешавад.
* **K2 (Феҳристи курсҳо ва номнависии донишҷӯ):**
  * `0` — Феҳристи онлайн ва номнависӣ вуҷуд надорад.
  * `1` — Феҳрист мавҷуд аст, аммо номнависӣ дастӣ, тавассути дархости почта ё тавассути паёмрасон сурат мегирад.
  * `2` — Феҳристи пурраи онлайн бо филтрҳо ва номнависии худкори фаврӣ ба курс мавҷуд аст.
* **K3 (Сохтори модулҳо, дарсҳо ва пайгирии пешрафт):**
  * `0` — Сохтори мураттаби дарсҳо вуҷуд надорад.
  * `1` — Курс ва дарсҳо ҳастанд, вале сохтори дақиқи бисёрмодулӣ ё пайгирии худкори пешрафт маҳдуд аст.
  * `2` — Сохтори сезинагии «Курс → Модул → Дарс», маводҳои гуногун (матн, видео) ва сабти худкори пешрафти ҳар дарс вуҷуд дорад.
* **K4 (Супоридани корҳои амалӣ ва баҳогузории омӯзгор):**
  * `0` — Воситаи супоридани супориши амалӣ вуҷуд надорад.
  * `1` — Танҳо тестҳои автоматӣ ё шакли оддии ҷамъоварии файлҳо мавҷуд аст, аммо санҷиши дастӣ, баҳо ва тақризи омӯзгор маҳдуд аст.
  * `2` — Механизми пурраи ирсоли файл аз ҷониби донишҷӯ ва интерфейси санҷиш, баҳогузорӣ ва шарҳнависии омӯзгор вуҷуд дорад.
* **K5 (Додани шаҳодатномаи электронӣ):**
  * `0` — Шаҳодатнома вуҷуд надорад.
  * `1` — Шаҳодатнома танҳо дар баъзе курсҳо, бо маҳдудият (масалан танҳо дар курсҳои пулакӣ) ё ба таври дастӣ дода мешавад.
  * `2` — Пас аз иҷрои 100%-и шартҳои курс шаҳодатномаи электронӣ бо рамзи нодири санҷишӣ ба таври худкор тавлид мегардад.
* **K6 (Забонҳои интерфейс: тоҷикӣ ва русӣ):**
  * `0` — На забони тоҷикӣ ва на забони русӣ дар интерфейс дастгирӣ намешавад.
  * `1` — Танҳо яке аз ин забонҳо (масалан русӣ) пурра дастрас аст ё тарҷумаи яке аз забонҳо (масалан тоҷикӣ) қисман мебошад.
  * `2` — Ҳам забони тоҷикӣ ва ҳам забони русӣ дар интерфейси платформа расман ва 100% пурра дастгирӣ мешаванд.
* **K7 (Мутобиқат ба телефон ва замимаи мобилӣ):**
  * `0` — Дар дастгоҳҳои мобилӣ қобили истифода нест.
  * `1` — Танҳо сомонаи мутобиқшаванда (Responsive Web) ё замимаҳои умумии ғайритаҳсилотӣ мавҷуданд.
  * `2` — Ҳам сомонаи босифати мутобиқшаванда ва ҳам барномаи махсуси мобилии омӯзишӣ (LMS App) мавҷуданд.
* **K8 (Арзиши истифода ва модели нархгузорӣ):**
  * `0` — Истифодаи нармафзор танҳо пулакӣ ва бо пардохти мунтазами литсензия барои ҳар корбар аст.
  * `1` — Курсҳои ройгон ё нақшаи озмоишӣ мавҷуданд, вале барои муаллифон ё ташкилот комиссия/пардохти иловагӣ талаб мешавад.
  * `2` — Нармафзори асосӣ кушода ё ройгон буда, барои шумораи дилхоҳи донишҷӯён бе пардохти иҷозатномаи мунтазам дастрас аст.
* **K9 (Имконияти ҷойгиркунӣ дар сервери худ):**
  * `0` — Танҳо модели абрӣ (SaaS) дар серверҳои хориҷӣ; имкони насб дар сервери шахсӣ нест.
  * `1` — Ҷойгиркунии маҳдуди идорашаванда ё имкони қисмакии содироти додаҳо.
  * `2` — Имконияти пурраи насб дар сервери шахсии маркази таълимӣ (Self-hosted) ва назорати комил бар пойгоҳи додаҳо.
* **K10 (Суръати саҳифа аз рӯи PageSpeed Insights):**
  * `0` — Холи маҳсулнокӣ (Performance Mobile) аз 0 то 49 (сатҳи суст).
  * `1` — Холи маҳсулнокӣ аз 50 то 89 (сатҳи миёна / қаноатбахш).
  * `2` — Холи маҳсулнокӣ аз 90 то 100 (сатҳи аъло).
  * `Н/Д` — Маълумот дастрас нест (агар аналог сомонаи вебии умумӣ барои санҷиш надошта бошад).

1. **SmartHub.tj ([М1]):**

   * *Маҳдудиятҳо:* Низоми мустақили шахсии эҷоди курс барои муаллифони беруна бо модератсияи худкор тасдиқ нашудааст; сомона замимаи махсуси мобилӣ надорад; имконияти насби нармафзор дар сервери шахсӣ мавҷуд нест.
2. **Stepik ([М2]):**
   * *Хусусиятҳои тасдиқшуда:* Сохтори мукаммали дарсҳо аз рӯи модулҳо ва қадамҳо (steps), воситаҳои сохтани курс барои муаллифон бо таҳлили оморӣ, додани шаҳодатномаи худкори электронӣ бо рамзи санҷишӣ дар курсҳои сертификатдор, мавҷудияти барномаҳои расмии мобилӣ барои Android ва iOS.
   * *Маҳдудиятҳо:* Тибқи шартҳои истифодабарии Stepik ([М2-Terms](https://www.stepik.org/terms)), платформа эҷоди озоди курсро иҷозат медиҳад, вале барои нашри курс модератсияи ҳатмии пешакӣ намегузаронад (бинобар ин K1 баҳои 1 мегирад). Барои фурӯши тиҷоратии курсҳо комиссия ситонида шуда, интерфейси система забони тоҷикиро дастгирӣ намекунад (танҳо русӣ ва англисӣ). Насб дар сервери шахсӣ вуҷуд надорад.
3. **Moodle LMS ([М3]):**
   * *Хусусиятҳои тасдиқшуда:* Нармафзори кушодаасос таҳти иҷозатномаи GNU GPL, назорати пурраи маълумот ва ҷойгиркунӣ дар сервери муассиса (Self-hosted), модули мукаммали Assignment барои санҷиши корҳои амалӣ ва шарҳнависии омӯзгор, барномаи расмии Moodle App.
   * *Маҳдудиятҳо:* Ҳарчанд нақши `Course creator` вуҷуд дорад ([М3-Creator](https://docs.moodle.org/502/en/Course_creator)), дар насби стандартии Moodle ҷараёни ҳатмии тасдиқ ва модератсияи курс пешбинӣ нашудааст (K1 баҳои 1 мегирад). Аз рӯи маълумоти расмии бастаҳои забонии Moodle ([М3-Lang](https://download.moodle.org/langpack/5.2/)), забони русӣ 100% буда, сатҳи тарҷумаи забони тоҷикӣ ҳамагӣ **45%**-ро ташкил медиҳад (K6 баҳои 1 мегирад).
4. **Udemy ([М4]):**
   * *Хусусиятҳои тасдиқшуда:* Феҳристи байналмилалии курсҳо бо ҷустуҷӯи пешрафта; муаллиф курс месозад ва пеш аз нашр санҷиши ҳатмии сифати видео (Quality Review Process) аз ҷониби Udemy сурат мегирад ([М4-Teach](https://teach.udemy.com/teaching-on-udemy/how-to-become-an-instructor-on-udemy/)) (K1 баҳои 2 мегирад); замимаҳои қулайи мобилӣ мавҷуданд.

Санҷиши дастии супоришҳо дар аксари курсҳо нест (K4 баҳои 1); забони тоҷикӣ дар интерфейс вуҷуд надорад; имкони насб дар сервери шахсӣ нест.
5. **Telegram + YouTube + Google Forms/Sheets ([М5]):**
   * *Хусусиятҳои тасдиқшуда:* Хизматрасониҳои ройгон бидуни пардохти литсензия; интерфейс ба забонҳои тоҷикӣ ва русӣ пурра фаъол аст; замимаҳои машҳури мобилӣ.
   * *Маҳдудиятҳо:* Набудани воситаи дохилии эҷод ва модератсияи мутамаркази курсҳо (K1 баҳои 0); набудани феҳристи ягона ва номнависии мутамарказ (K2 баҳои 1); дар YouTube плейлист пайдарпайии дарсҳоро дорад, вале назорати худкори пешрафт дар система нест (K3 баҳои 1); таҳвили ҷавобҳо тавассути Forms сурат мегирад, вале журнали муттаҳиди баҳодиҳӣ нест (K4 баҳои 1); шаҳодатномаи худкор вуҷуд надорад (K5 баҳои 0); замимаи махсуси таҳсилотии LMS вуҷуд надорад (K7 баҳои 1); маълумот дар серверҳои хориҷӣ пароканда аст (K9 баҳои 0).

## 3. Матритсаи муқоисавӣ

Дар ҷадвали зерин баҳогузории 5 аналоги воқеӣ дар муқоиса бо ҳадафи тарҳрезишудаи лоиҳаи «Biyomuz» пешниҳод шудааст. Ҳар як хонача дорои баҳо (0, 1, 2 ё Н/Д), шарҳи кӯтоҳи асосноккунанда ва рамзи манбаъ мебошад.

| Рамз ва меъёр (Вазн) | SmartHub.tj | Stepik | Moodle LMS | Udemy | Telegram + Google | Ҳадафи Biyomuz |

## 4. Ҳисобҳои ҷамъбастӣ ва натиҷаҳо

Барои ҳар як аналог баҳо бо вазни меъёр зарб зада шуда, ҷамъбаст гардид. Барои аналогҳое, ки дар онҳо меъёри муайян бо сабаби татбиқнашавандагӣ ё хусусияти меъморӣ санҷида нашудааст (`Н/Д`), вазни ҳамон меъёр аз холҳои ҳадди аксар (\(S_{max}\)) тарҳ карда шудааст.

### 4.1. Формулаҳои ҳисоб:
$$S = \sum (\text{Баҳо} \times \text{Вазн})$$
$$S_{max} = 2 \times \sum \text{Вазнҳои меъёрҳои ченшуда}$$
$$\text{Фоиз} = \frac{S}{S_{max}} \times 100\%$$

### 4.2. Тафсилоти ҳисоби ҳар як аналог:

1. **SmartHub.tj:**
   * Ҳамаи 10 меъёр чен карда шуданд (\(S_{max} = 48\)).
   * \(S = (1 \times 2) + (2 \times 3) + (1 \times 3) + (1 \times 3) + (1 \times 2) + (2 \times 3) + (1 \times 2) + (1 \times 2) + (0 \times 2) + (1 \times 2)\)
   * \(S = 2 + 6 + 3 + 3 + 2 + 6 + 2 + 2 + 0 + 2 = \mathbf{28}\)
   * **Фоиз:** \(\frac{28}{48} \times 100\% = \mathbf{58.33\%}\)

2. **Stepik:**
   * 9 меъёр чен карда шуд (K10 — `Н/Д`, вазни 2 тарҳ шуд: \(S_{max} = 48 - 4 = \mathbf{44}\)).
   * \(S = (1 \times 2) + (2 \times 3) + (2 \times 3) + (2 \times 3) + (2 \times 2) + (1 \times 3) + (2 \times 2) + (1 \times 2) + (0 \times 2)\)
   * \(S = 2 + 6 + 6 + 6 + 4 + 3 + 4 + 2 + 0 = \mathbf{33}\)
   * **Фоиз:** \(\frac{33}{44} \times 100\% = \mathbf{75.00\%}\)

3. **Moodle LMS:**
   * 9 меъёр чен карда шуд (K10 — `Н/Д`, вазни 2 тарҳ шуд: \(S_{max} = 48 - 4 = \mathbf{44}\)).
   * \(S = (1 \times 2) + (2 \times 3) + (2 \times 3) + (2 \times 3) + (2 \times 2) + (1 \times 3) + (2 \times 2) + (2 \times 2) + (2 \times 2)\)
   * \(S = 2 + 6 + 6 + 6 + 4 + 3 + 4 + 4 + 4 = \mathbf{39}\)
   * **Фоиз:** \(\frac{39}{44} \times 100\% = \mathbf{88.64\%}\)

4. **Udemy:**
   * 9 меъёр чен карда шуд (K10 — `Н/Д`, вазни 2 тарҳ шуд: \(S_{max} = 48 - 4 = \mathbf{44}\)).
   * \(S = (2 \times 2) + (2 \times 3) + (2 \times 3) + (1 \times 3) + (1 \times 2) + (1 \times 3) + (2 \times 2) + (0 \times 2) + (0 \times 2)\)
   * \(S = 4 + 6 + 6 + 3 + 2 + 3 + 4 + 0 + 0 = \mathbf{28}\)
   * **Фоиз:** \(\frac{28}{44} \times 100\% = \mathbf{63.64\%}\)

5. **Telegram + YouTube + Google Forms/Sheets:**
   * 9 меъёр чен карда шуд (K10 — `Н/Д`, вазни 2 тарҳ шуд: \(S_{max} = 48 - 4 = \mathbf{44}\)).
   * \(S = (0 \times 2) + (1 \times 3) + (1 \times 3) + (1 \times 3) + (0 \times 2) + (1 \times 3) + (1 \times 2) + (2 \times 2) + (0 \times 2)\)
   * \(S = 0 + 3 + 3 + 3 + 0 + 3 + 2 + 4 + 0 = \mathbf{18}\)
   * **Фоиз:** \(\frac{18}{44} \times 100\% = \mathbf{40.91\%}\)

### 4.3. Ҷадвали ҷамъбастии рейтинг

| Ҷой | Номи аналог | Холи бадастомада (\(S\)) | Холи ҳадди аксар (\(S_{max}\)) | Фоизи мувофиқат |

## 5. Хулоса ва қарорҳои лоиҳа

Таҳлили муқоисавӣ нишон дод, ки ҳарчанд низомҳои байналмилалӣ (Stepik, Udemy) ва системаҳои кушода (Moodle) имкониятҳои васеъ доранд, ягон аналоги мавҷуда ба таври комил ба эҳтиёҷоти маркази таълимии маҳаллӣ ҷавобгӯ нест.

### 5.1. Қарорҳое, ки аз аналогҳо мегирем:
1. **Сохтори мураттаби дарсҳо ва пайгирии қадамҳо (Меъёри K3 — аз Stepik):**
   Аз таҷрибаи платформаи Stepik мо сохтори иерархикии сезинагии «Курс → Модул → Дарс» ва пайгирии худкори дарсҳои хондашударо қабул мекунем, ки омӯзишро пайдарпай ва фаҳмо мегардонад.
2. **Модули супориш ва баҳогузории муаллиф бо тақриз (Меъёри K4 — аз Moodle LMS):**
   Аз низоми Moodle механизми дақиқи супоридани супоришҳо (`Assignment`), боркунии файлҳои ҷавоб (`AssignmentSubmission`) ва гузоштани баҳо бо шарҳи тавсиявии омӯзгор гирифта мешавад.
3. **Феҳристи соддаи курсҳо бо филтрҳо ва шаҳодатномаи худкор (Меъёрҳои K2, K5 — аз SmartHub.tj ва Stepik):**
   Аз SmartHub тарзи содда ва мутобиқ ба бозори маҳаллии феҳристи курсҳо бо филтрҳои нарх ва забон, инчунин аз Stepik механизми тавлиди шаҳодатномаи рақамии дорои рамзи беназири санҷишӣ (Verification Code) гирифта мешавад.
