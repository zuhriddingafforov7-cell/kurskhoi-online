## 2. Мушаххасоти муҳити санҷиш ва сабти тасвирҳо

- **СУБД:** MariaDB 10.4.32 (XAMPP for Windows, порти 3306).
- **Интерфейси идоракунӣ:** phpMyAdmin 5.2.1.
- **Суроғаи маҳаллӣ:** [http://localhost/phpmyadmin/](http://localhost/phpmyadmin/).
- **Номи пойгоҳи додаҳо:** `kurskhoi_online`.
- **Рамзгузорӣ:** `utf8mb4`.
- **Муқоисаи рамзҳо (Collation):** `utf8mb4_unicode_ci`.
- **Муҳаррики нигоҳдорӣ:** InnoDB барои ҳамаи 10 ҷадвали пойгоҳи додаҳо.
- **Тарзи гирифтани скриншотҳо:** Тасвирҳо аз интерфейси воқеии phpMyAdmin тавассути браузери Chrome Headless бо истифода аз Chrome DevTools Protocol (CDP) гирифта шудаанд.
- **Андозаи скриншотҳо:** 1582 × 954 пиксел.

## 3. Мақсади истифодаи скриншотҳо

Скриншотҳо ҳамчун далели визуалии иҷрои қисми амалии Лабораторияи №7 истифода мешаванд:

1. Иҷрои дархости SQL ва гирифтани натиҷаи он.
2. Намоиши сохтори физикии пойгоҳи додаҳо ва робитаҳои байни ҷадвалҳо.
3. Тасдиқи дурустии намоиши додаҳои тоҷикӣ бо рамзгузории `utf8mb4`.

Ин далелҳо қисми ҳуҷҷатгузории техникии лоиҳаи Biyomuz Academy мебошанд.
