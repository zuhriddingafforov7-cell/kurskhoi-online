# Супориши кӯтоҳи техникӣ: Biyomuz Academy

**Лоиҳа:** «Biyomuz Academy»<br>
**Сана:** 09.11.2026 | **Муаллиф:** Ғаффоров З. Ҳ. | **Ҳолат:** Марҳилаи лоиҳакашӣ

---

## 1. Мақсад ва ҳадафҳои лоиҳа
Лоиҳаи **Biyomuz Academy** платформаи таълими электрониро барои омӯзиши онлайн фароҳам меорад. Ҳадафҳои лоиҳа сабти худкори пешрафт ва таъмини санҷиши супоришҳо дар давоми то 1 рӯзи корӣ мебошанд.

## 2. Нақшҳои истифодабарандагон
Нақшҳои система тибқи [Таҳлили соҳаи предметӣ](01-domain-analysis.md) муайян шудаанд:
* **`guest`** — меҳмон;
* **`student`** — донишҷӯ;
* **`author`** — муаллифи курс;
* **`admin`** — маъмури платформа.

## 4. Таърихчаҳои истифодабарандагон

**US-01 (FR-02). Бақайдгирии меҳмон**
Ҳамчун `guest`, мехоҳам сабти ном шавам, то дастрасии донишҷӯ гирам.
- Дода шудааст: маълумоти дуруст дар `/register`. Вақте: сабт пахш мешавад. Он гоҳ: ҳисоби `student` сохта шуда, саҳифаи шахсӣ боз мешавад.
- Дода шудааст: почтаи қаблан сабтшуда. Вақте: сабти такрорӣ мешавад. Он гоҳ: ҳисоб сохта нашуда, хатогӣ дода мешавад.

**US-02 (FR-04, FR-05). Номнависӣ ва омӯзиш**
Ҳамчун `student`, мехоҳам ба курс номнавис шуда, пайдарпай омӯзам.
- Дода шудааст: курси нашршуда. Вақте: «Номнавис шудан» пахш мешавад. Он гоҳ: номнависӣ сабт ва дарси 1 кушода мешавад.
- Дода шудааст: хатми дарси ҷорӣ. Вақте: ба дарси баъдӣ мегузарад. Он гоҳ: пешрафт сабт ва дарси навбатӣ боз мешавад.
- Дода шудааст: дарси басташуда. Вақте: кӯшиши кушодан мешавад. Он гоҳ: дастрасӣ бо рамзи 403 маҳдуд мешавад.

**US-03 (FR-06). Ирсоли супориш**
Ҳамчун `student`, мехоҳам файли корро фиристам, то санҷида шавад.
- Дода шудааст: супориши дарс. Вақте: файл то 5 МБ бор мешавад. Он гоҳ: ҳолат ба `submitted` иваз мешавад.
- Дода шудааст: файли беш аз 5 МБ. Вақте: боркунӣ мешавад. Он гоҳ: файл рад шуда, огоҳинома намоиш меёбад.

**US-04 (FR-08). Санҷиш ва баҳогузорӣ**
Ҳамчун `author`, мехоҳам кори донишҷӯро санҷида баҳо диҳам.
- Дода шудааст: супориш дар ҳолати `submitted`. Вақте: баҳо ва шарҳ гузошта мешавад. Он гоҳ: ҳолат ба `approved` табдил меёбад.
- Дода шудааст: баҳои камтар аз 0 ё бештар аз 100. Вақте: сабт мешавад. Он гоҳ: баҳо рад шуда, хатогӣ дода мешавад.

**US-05 (FR-09). Модератсияи курс**
Ҳамчун `admin`, мехоҳам курсҳоро санҷида тасдиқ ё рад кунам.
- Дода шудааст: курс дар ҳолати `pending`. Вақте: маъмур тасдиқ мекунад. Он гоҳ: ҳолат ба `published` табдил меёбад.
- Дода шудааст: курси номувофиқ. Вақте: маъмур бо сабаб рад мекунад. Он гоҳ: ҳолат ба `rejected` табдил ва сабаб ба муаллиф мерасад.
- Дода шудааст: нақши `student`. Вақте: кӯшиши тасдиқи курс мешавад. Он гоҳ: дастрасӣ бо рамзи 403 манъ шуда, ҳолат тағйир намеёбад.

**US-06 (FR-07). Эҷоди курс**
Ҳамчун `author`, мехоҳам курс ва дарс сохта, ба санҷиш фиристам.
- Дода шудааст: маълумоти пурраи курс. Вақте: ба санҷиш фиристода мешавад. Он гоҳ: ҳолат ба `pending` иваз мешавад.
- Дода шудааст: майдони холии ҳатмӣ. Вақте: ирсол мешавад. Он гоҳ: дархост рад ва хатогӣ нишон дода мешавад.

**US-07 (FR-10). Гирифтани шаҳодатнома**
Ҳамчун `student`, мехоҳам баъди хатми курс шаҳодатнома гирам.
- Дода шудааст: хатми 100% дарсҳо ва супоришҳо. Вақте: шаҳодатнома пурсида мешавад. Он гоҳ: файли PDF бо рамзи санҷишӣ дода мешавад.
- Дода шудааст: курси нопурра. Вақте: шаҳодатнома дархост мешавад. Он гоҳ: санад дода нашуда, сабаб баён мегардад.

## 6. Маҳдудиятҳои техникӣ
1. **Воситаҳои таҳия:** PHP 8.3+ (муҳити таҳия PHP 8.5.10), Laravel 13, Blade, Tailwind CSS 4 ва JavaScript.
2. **Сервер ва пойгоҳи додаҳо:** XAMPP, MariaDB 10.4.32 (бо дархости SELECT VERSION(); тасдиқ шудааст), рамзгузории utf8mb4_unicode_ci.
3. **Муҳлати иҷро ва гурӯҳи таҳия:** як семестри таълимӣ, як донишҷӯ-таҳиягар.

## 7. Афзалиятбандии MoSCoW
* **Must (Ҳатмӣ):** FR-01–FR-09. Барои фаъолияти асосии платформа ҳатмианд.
* **Should (Муҳим):** FR-10, FR-11. Барои марҳилаи аввал шарт нестанд.
* **Could (Иловагӣ):** FR-12. Содирот ба CSV имконияти иловагӣ мебошад.
* **Won't (Дар ин версия амалӣ намешавад):** FR-13, FR-14. Пардохт ва пахши мустақим амалӣ намешаванд.

## 8. MVP ва берун аз ҳудуди лоиҳа
### Сенарияи пайдарпайи MVP
Ба MVP талаботи Must (FR-01–FR-09) шомиланд. Шаҳодатнома (FR-10) ба версияи навбатӣ мегузарад:
1. `author` курсро сохта, ба санҷиш мефиристад (FR-07).
2. `admin` курсро санҷида тасдиқ мекунад (FR-09).
3. `guest` сабти ном карда, соҳиби ҳисоби `student` мегардад (FR-02, FR-03).
4. `student` ба курси нашршуда номнавис шуда, меомӯзад (FR-01, FR-04, FR-05).
5. `student` супоришро бо файл мефиристад (FR-06).
6. `author` супоришро санҷида, баҳо мегузорад (FR-08).

### Берун аз ҳудуди лоиҳа
1. Барномаи мустақили мобилӣ барои iOS ва Android.
2. Низоми пардохти мустақими бонкӣ дар платформа.
3. Пахши мустақими видео дар дохили платформа.
