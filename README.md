# DonoHub — Веб-платформа онлайн-курсов

## О проекте
**DonoHub** — независимая современная веб-платформа для дистанционного обучения и управления образовательными курсами. Система предоставляет удобную цифровую среду для студентов, преподавателей и администрации учебного центра.

* **Тема из силлабуса:** «Коркарди веблоиҳаи платформаи курсҳои онлайн» (Разработка веб-проекта платформы онлайн-курсов)
* **Тип проекта:** Информационная система (ИС)
* **Студент (Автор):** Ғаффоров Зуҳриддин (`zuhriddingafforov7@gmail.com`)

* **Дисциплина:** Технологии и языки интернет-программирования
* **Преподаватель:** @Ghanijon

## Технологический стек
* **Backend:** PHP 8.5+, Laravel 13
* **База данных:** MySQL 8+
* **Frontend:** Blade, HTML5, CSS3, JavaScript
* **Контроль версий:** Git, GitHub
* **Локальное окружение:** Windows, PowerShell, XAMPP / Composer
