## 2. Мақсадҳои асосии система
- Таъсиси муҳити ягона ва мутамаркази таълимӣ барои донишҷӯён ва муаллифон.
- Содда ва худкор кардани раванди бақайдгирӣ, номнависӣ ба курсҳо ва дастрасӣ ба маводи таълимӣ.
- Таъмини назорати пайдарпайии омӯзиши дарсҳо ва ҳисоби дақиқи пешрафти инфиродӣ.
- Фароҳам овардани низоми санҷиши супоришҳои амалӣ ва баҳогузории шаффоф.
- Тавлиди худкори шаҳодатномаи электронӣ баъди хатми бомуваффақияти курс.

---

## 3. Нақшҳои истифодабарандагон
Дар система модели чаҳоргонаи нақшҳо амал мекунад:
1. **`guest` (Меҳмон):** Корбари сабтиномнашуда, ки имконияти дидани саҳифаи асосӣ, шиносоӣ бо феҳристи курсҳо ва гузаштани бақайдгириро дорад.
2. **`student` (Донишҷӯ):** Корбари сабтиномшуда, ки ба курсҳо номнавис мешавад, дарсҳоро пайдарпай меомӯзад, корҳои амалиро месупорад ва пешрафти худро пайгирӣ мекунад.
3. **`author` (Муаллифи курс):** Мутахассисе, ки курсҳо, модулҳо ва дарсҳоро месозад, супоришҳои амалиро таъин мекунад ва корҳои ирсолшудаи донишҷӯёнро месанҷад.
4. **`admin` (Маъмур):** Роҳбари низоми платформа, ки ҳисобҳо ва нақшҳоро танзим мекунад, категорияҳоро идора менамояд ва курсҳоро пеш аз нашр санҷида тасдиқ мекунад.

## 4. Имкониятҳои платформа

### Тарҳрезишуда (Марҳилаи лоиҳакашӣ — ҳоло):
- Муайянсозии соҳаи предметӣ ва нақшҳо (Лабораторияи №1).
- Таҳлили аналогҳо ва моделсозии равандҳои корӣ.
- Лоиҳакашии пойгоҳи додаҳо ва интерфейс.

### Нақшавӣ (Марҳилаи таҳия — оянда):
- Системаи аутентификатсия ва иҷозатдиҳии вобаста ба нақш (Role-based Access Control).
- Кабинети шахсӣ барои донишҷӯ, муаллиф ва маъмурият.
- Муҳаррири сохтани дарсҳои матнӣ ва видеоӣ.
- Низоми фиристодани корҳои амалӣ ва баҳогузорӣ бо шарҳ.
- Модули тавлиди худкори шаҳодатнома.
