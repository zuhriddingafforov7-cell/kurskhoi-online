## 2. Мақсадҳои асосии система
- Таъсиси муҳити ягона ва мутамаркази таълимӣ барои донишҷӯён ва муаллифон.
- Содда ва худкор кардани раванди бақайдгирӣ, номнависӣ ба курсҳо ва дастрасӣ ба маводи таълимӣ.
- Таъмини назорати пайдарпайии омӯзиши дарсҳо ва ҳисоби дақиқи пешрафти инфиродӣ.
- Фароҳам овардани низоми санҷиши супоришҳои амалӣ ва баҳогузории шаффоф.
- Тавлиди худкори шаҳодатномаи электронӣ баъди хатми бомуваффақияти курс.

---

## 3. Нақшҳои истифодабарандагон
Дар система модели чаҳоргонаи нақшҳо амал мекунад:
1. **`guest` (Меҳмон):** Корбари сабтиномнашуда, ки имконияти дидани саҳифаи асосӣ, шиносоӣ бо феҳристи курсҳо ва гузаштани бақайдгириро дорад.
2. **`student` (Донишҷӯ):** Корбари сабтиномшуда, ки ба курсҳо номнавис мешавад, дарсҳоро пайдарпай меомӯзад, корҳои амалиро месупорад ва пешрафти худро пайгирӣ мекунад.
3. **`author` (Муаллифи курс):** Мутахассисе, ки курсҳо, модулҳо ва дарсҳоро месозад, супоришҳои амалиро таъин мекунад ва корҳои ирсолшудаи донишҷӯёнро месанҷад.
4. **`admin` (Маъмур):** Роҳбари низоми платформа, ки ҳисобҳо ва нақшҳоро танзим мекунад, категорияҳоро идора менамояд ва курсҳоро пеш аз нашр санҷида тасдиқ мекунад.

## 4. Имкониятҳои платформа

### Тарҳрезишуда (Марҳилаи лоиҳакашӣ — ҳоло):
- Муайянсозии соҳаи предметӣ ва нақшҳо (Лабораторияи №1).
- Таҳлили аналогҳо ва моделсозии равандҳои корӣ.
- Лоиҳакашии пойгоҳи додаҳо ва интерфейс.

### Нақшавӣ (Марҳилаи таҳия — оянда):
- Системаи аутентификатсия ва иҷозатдиҳии вобаста ба нақш (Role-based Access Control).
- Кабинети шахсӣ барои донишҷӯ, муаллиф ва маъмурият.
- Муҳаррири сохтани дарсҳои матнӣ ва видеоӣ.
- Низоми фиристодани корҳои амалӣ ва баҳогузорӣ бо шарҳ.
- Модули тавлиди худкори шаҳодатнома.

## Прецедентҳои асосии Biyomuz
Дар доираи моделсозии рафтори система (Лабораторияи №4), се прецеденти калидии истифода муайян шудаанд:
1. **Бақайдгирӣ ва номнависии донишҷӯ (`guest`, `student`):** Меҳмон дар платформа сабти ном карда, ҳисоби донишҷӯро фаъол мекунад ва ба курси нашршуда номнавис мешавад.
2. **Эҷод ва модератсияи курс (`author`, `admin`):** Муаллиф маводи курс, модул ва дарсҳоро таҳия намуда, ба санҷиш мефиристад; маъмур онро баррасӣ карда, тасдиқ (нашр) ё бо сабти сабаб рад менамояд.
3. **Ирсол ва санҷиши супориши амалӣ (`student`, `author`):** Донишҷӯ файли супориши амалиро бор мекунад ва муаллиф онро санҷида, баҳо ва шарҳи худро мегузорад.

## Модели сохтори система ва ҷадвалҳои пойгоҳи додаҳо (Лабораторияи №5)
Дар доираи моделсозии сохтории платформаи Biyomuz Academy (Лабораторияи №5), синфҳои предметӣ ва барномавӣ ба чунин бахшҳо ҷудо мешаванд:
1. **Синфҳои предметӣ, ки ба ҷадвалҳои пойгоҳи додаҳо табдил мешаванд:**
   - **Ҷадвалҳои аллакай сохташуда дар Laravel Migration:** `User` (`users`), `Category` (`categories`), `Course` (`courses`).
   - **Объектҳои пешбинишуда дар модели предметӣ (ҳоло бидуни Migration):** `Module` (`modules`), `Lesson` (`lessons`), `Assignment` (`assignments`), `AssignmentSubmission` (`assignment_submissions`), `Enrollment` (`enrollments`), `Certificate` (`certificates`). Муҳоҷирати ин ҷадвалҳо дар марҳилаҳои минбаъда (лабораторияҳои №6–7 ва №10+) таҳия карда мешавад.
2. **Синфҳои барномавӣ барои мантиқ ва идоракунӣ:**
   - `CourseController` — қабули дархостҳои HTTP, санҷиши иҷозатҳо (`auth`, нақши `author`) ва идоракунии масирҳои бозгашт.
   - `CourseRepository` — қабати ҷудогонаи дастрасӣ ба додаҳо барои эҷод ва истихроҷи курсҳо (`createOrSubmit`).
   - `Database` — абстраксияи пайвасти Laravel ба СУБД (PDO / Database Connection).
