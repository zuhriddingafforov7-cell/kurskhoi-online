# Biyomuz — Платформаи курсҳои онлайн

## Дар бораи лоиҳа
**Biyomuz** — бренди мустақил ва муосири платформаи вебии таҳсилоти фосилавӣ ва идоракунии курсҳои таълимӣ мебошад.

* **Номи асосии бренд:** Biyomuz
* **Номи расмии платформа:** Biyomuz Academy
* **Номи намоишӣ барои сомона ва реклама:** Biyomuz Online
* **Мавзӯъ аз рӯи силлабус:** «Коркарди веблоиҳаи платформаи курсҳои онлайн»
* **Намуди лоиҳа:** Системаи иттилоотӣ (ИС)
* **Донишҷӯ (Муаллиф):** Ғаффоров Зуҳриддин (`zuhriddingafforov7@gmail.com`)
* **Гурӯҳ:** [Рақами гурӯҳи худро нависед]
* **Фан:** Технологияҳо ва забонҳои барномасозии интернетӣ
* **Омӯзгор:** @Ghanijon

## Маҷмӯи технологияҳо (Tech Stack)
* **Backend:** PHP 8.5+, Laravel 13
* **Пойгоҳи додаҳо (Database):** MySQL 8+
* **Frontend:** Blade, HTML5, CSS3, JavaScript
* **Идоракунии версияҳо:** Git, GitHub
* **Муҳити маҳаллӣ:** Windows, PowerShell, XAMPP / Composer
